# OI（Olympiad in Informatics）介绍

## IOI

* 收录了1994~2002年的试题与解析。

## NOI

* 收录了1991~2009、2024、2025年的试题、解析与测试数据。

## NOIP

* 收录了1995~2018年的初赛试题与参考答案。
* 收录了1995~2018年的复赛试题、部分测试数据与参考程序。
* 2019年，CCF停办了一次NOIP，之后，NOIP就没有之前所谓的初赛了。
* 收录了2020~2025年的复赛试题、部分测试数据与参考程序。
* 书《全国青少年信息学（计算机）奥林匹克分区联赛试题解析（中学）》南京大学出版社。
  * NOIP第一本试题解析，南京大学出版社于2001年出版，收录了1995-2000年的试题及解析。发行量较小。

## CSP-J/S

* 收录了2019~2025年第一轮试题与部分参考答案。
* 收录了2019~2025年第二轮试题、部分测试数据与参考程序。
